### Version control:git and github
**Everyone must know how to use github**
```
- Everyone must have the github accounts ready
- We will make a repo under the organisation in GitHub
- The repo is live under the org and not any one person solves the jealousy issue 
- You can give teammates "Owner" or "Admin" roles too, so it's not a single point of failure
- Everyone can pull and push code 
```
```
- GitHub Actions will be set so they prevent code from breaking anything
- Everyone will make a .gitignore to prevent leaking secrets
- Use a .env.example file so everyone knows what environment variables are needed without secrets being in the repo.
- We will write the pitch in the README file so everyone knows what we are doing 
```
